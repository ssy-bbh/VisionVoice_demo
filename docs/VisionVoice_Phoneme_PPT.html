第一部分 · 项目概述与核心挑战

VisionVoice 简介

AR英语学习应用的端侧AI发音评估

  • 核心目标：零网络延迟、高隐私安全的专业级发音评估
  • 技术方案：端侧离线推理，无需网络连接
  • 应用场景：AR物体识别 → 单词学习 → 发音练习
  • 性能指标：推理时间 < 320ms，模型体积 ~300MB

挑战一：模型领域错位 (Domain Mismatch)

ASR模型输出字母，评估基准使用音标

📥 输入音频
↓
Wav2Vec2-base → "A-P-P-L-E" (英文字母)
≠
CMU Dict → "AE P L" (Arpabet音素)
❌ 问题：跨维度特征不匹配
结果：对所有发音均打出 0分

挑战二：异构数据源符号域冲突

Unicode IPA vs ASCII Arpabet 字符不匹配

📖 词典路径 (标准答案)

遵循语言学家规范

ɹ, æ, ɔ

Unicode 国际音标

🤖 AI模型路径 (识别结果)

遵循深度学习标注规范

r, ae, ao

ASCII Arpabet音标

❌ Java字符串比较："ɹ".equals("r") → false
即使发音完全正确，系统依然判定为错读！

挑战三：声学物理干扰

清塞音(/p/, /t/, /k/)气流冲击麦克风

👄 用户发音清塞音 /k/
↓ 瞬间释放高压气流
📱 冲击手机麦克风振膜 → 非线性失真
↓
🤖 AI识别为 /hh/ 而非 /k/

第四部分 · 双重归一化架构

4.1 跨服聊天的"巴别塔难题"

现象：完全正确的发音被判定为错读

标准音标: i ← 完全匹配 → i :识别音标

❌ 判定结果: 错读 (标红)
根本原因：Unicode与ASCII编码不同
"ɹ".equals("r") → false

4.2 双层翻译机制

彻底剥离比对逻辑与渲染逻辑

Level 1: 底层降维
Unicode IPA → ASCII Arpabet
↓
Level 2: 对齐运算
Needleman-Wunsch Alignment
↓
Level 3: 表层升维
ASCII Arpabet → Unicode IPA
核心思想：算法用粗糙的Arpabet计算，UI显示专业的国际音标

第五部分 · 序列对齐与评分算法

5.1 Needleman-Wunsch全局对齐

定制化序列对齐算法

⚠️ 问题：用户发音长度 ≠ 标准发音长度（吞音或多读）
权重参数分值说明
MATCH+1.0完全匹配
FLAW+0.5发音瑕疵
MISMATCH-1.0错读
GAP-1.0漏读/多读

5.2 对齐矩阵示意

标准序列 vs 用户序列

标准音素: A   E   P   L
用户音素: A       P   L

对齐分析：
A → MATCH ✓ | [GAP] → Gap(-1) | P → MATCH ✓ | L → MATCH ✓

计算：(3 - 1) / 3 = 0.67

第六部分 · 声学容错矩阵

6.1 物理抗噪：爆破音气流干扰

Plosive Puff Effect 解决方案

↓ 高压气流冲击麦克风
物理失真 → AI识别为 /hh/
↓
✅ 工程解决：k → hh 判定为完全匹配

6.2 SLA理论分级惩罚

基于Munro & Derwing (1995) 第二语言习得理论

等级类型判定分数示例
一级完全豁免Ignored→Match100分长短元音偏差
二级发音瑕疵Flaw60分梅花音张口不足
三级严重错读Substitution0分破坏语义
核心思想：可理解度(Intelligibility) > 母语者口音(Accentedness)
